# processhoops analytics

## Visão

O processhoops analytics é uma plataforma moderna de análise estatística de basquete, construída inicialmente para a NBA utilizando exclusivamente tecnologias gratuitas.

O projeto nasce com foco na NBA, mas sua arquitetura deverá permitir expansão futura para outras ligas e competições sem necessidade de reestruturação significativa.

O objetivo não é apenas exibir estatísticas.

O objetivo é transformar dados em ferramentas de exploração, comparação e descoberta, permitindo que qualquer fã de basquete compreenda rapidamente o contexto por trás dos números.

O processhoops analytics deverá transmitir a sensação de um produto profissional, priorizando experiência do usuário, velocidade, organização visual e interatividade.
